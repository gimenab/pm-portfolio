# Gimena Fernandez, Project Manager Portfolio

Case studies and tools from a project manager who also builds her own tools.

- **Treasure Time:** a project case study that follows one product through the whole project cycle, step by step.
- **PM-AI-Workflow:** a system of AI skills and subagents that automates the repeatable work of project management.

Static site, plain HTML and Tailwind CSS via CDN. No build step.

Live: https://gimenab.github.io/pm-portfolio/
